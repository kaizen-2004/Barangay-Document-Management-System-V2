Barangay Document Management System - Deployment Instructions
=============================================================

OPTION A: Python-based (recommended)
-------------------------------------

Step 1 — Install Python
  1. Go to https://python.org and download Python 3.12+
  2. Run installer, CHECK "Add python.exe to PATH", click Install

Step 2 — Install Git
  1. Go to https://git-scm.com and download Git for Windows
  2. Run installer (default options)

Step 3 — Install uv (fast package manager)
  Open PowerShell and run:

     powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

  Close and reopen your terminal after install.

Step 4 — Deploy
  Open Command Prompt and run:

     cd C:\
     git clone <repo-url> barangay
     cd barangay
     uv sync
     start.bat

Step 5 — Create desktop shortcut
  Right-click desktop -> New -> Shortcut
  Location: C:\barangay\start-ssl.bat
  Name: Barangay System

Step 6 — Run
  Double-click the shortcut.
  Browser opens at http://localhost:5000 (or https://localhost:5000 with --ssl).
  Log in with admin / admin.
  If other PCs can't access, run setup-firewall.bat as Administrator.


OPTION B: Standalone .exe (no Python needed on target PC)
----------------------------------------------------------

Build the .exe once (on any machine with the source code):

  On Windows — open Command Prompt in the project folder and run:

       uv sync
       uv run build.bat

  The .exe will be at:  dist\BarangaySystem\BarangaySystem.exe

Copy the entire dist\BarangaySystem\ folder to any Windows PC.

On that PC:
  - Create a desktop shortcut pointing to BarangaySystem.exe
  - Double-click it to run

  That's it. No Python, no Git, no setup needed.

  First run: creates the database, seeds admin/admin user,
  generates SSL cert, and opens the browser automatically.


Notes
-----
- No external apps (LibreOffice, MySQL, openssl) needed.
- Default database is SQLite (file stored in data/ folder).
- HTTPS uses a Python-generated self-signed certificate.
- PDF conversion via LibreOffice is skipped if unavailable;
  the system serves .docx files instead.
- Login: admin / admin  (change password after first login).
- Background removal works fully offline (no internet required).
