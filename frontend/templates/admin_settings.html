QR Code Verification

When set, QR codes on printed documents link to this URL instead of the local server. This makes QR codes work from any network, even after printing.
Google Drive setup:
1. Run python scripts/generate_verification_image.py to create the image
2. Upload to Google Drive → Share → "Anyone with the link"
3. Copy the file ID from: https://drive.google.com/file/d/FILE_ID/view
4. Paste above as: https://drive.usercontent.google.com/download?id=FILE_ID&export=view
